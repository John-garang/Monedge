## 🚀 How to Run Locally

1. **Clone or Download** the project files to your local machine
2. **Open the project** in VS Code or your preferred editor
3. **Launch the website** by either:
   - Opening `index.html` directly in your web browser
   - Using VS Code's Live Server extension (recommended)
   - Setting up a local web server

### Using VS Code Live Server (Recommended)

1. Install the "Live Server" extension in VS Code
2. Right-click on `index.html`
3. Select "Open with Live Server"
4. The website will open in your default browser with auto-reload functionality

## 🔧 Customization Guide

### Replacing Placeholder Images

The website currently uses high-quality stock images from Unsplash. To replace with custom images:

1. Add your images to the `assets/images/` folder
2. Update the `src` attributes in `index.html`
3. Recommended image sizes:
   - Hero image: 800x600px
   - Service icons: 400x400px
   - About section: 600x400px
   - Feature icons: 300x300px

### Updating Content

- **Company Information:** Edit the text content in `index.html`
- **Contact Details:** Update phone numbers and email in both HTML and any JavaScript references
- **Services:** Modify the service cards in the Services section
- **Colors:** Update CSS variables in `:root` section of `style.css`

### Adding New Sections

1. Add the HTML structure in `index.html`
2. Add corresponding styles in `style.css`
3. Update navigation links if needed
4. Add any interactive functionality in `main.js`

## 🛠 Development Notes

### Form Handling
The contact form currently uses client-side validation and simulation. For production:
1. Add server-side form processing
2. Implement proper email sending functionality
3. Add CAPTCHA for spam protection
4. Store form submissions in a database

### Image Optimization
For production deployment:
1. Compress all images
2. Use WebP format where supported
3. Implement responsive images with `srcset`
4. Consider using a CDN for image delivery

### SEO Enhancements
For better search engine optimization:
1. Add more detailed meta descriptions
2. Implement structured data markup
3. Add Open Graph tags for social sharing
4. Create an XML sitemap
